Radio Race

Three LEGO cars, three wands, one shared radio. Drive your car by waving the wand — then try to hijack someone else's. Each round locks the radio down a little more, and the attacker has to work harder to keep winning.

The devices

Driver

The Wand

Your controller. Hold the button and move the wand to drive; let go and the car stops.

  • Sends F / T / P over ESP-NOW
  • Button is a dead-man switch — release always means stop
  • An NFC card flips it to the next round (and carries the key)
View wand code
The car

The Bridge

Rides on the car. Receives the radio command and drives the LEGO motor over Bluetooth.

  • ESP-NOW in, BLE out to the LEGO Double Motor
  • One bridge per car
  • The same NFC card turns on decryption for round 3
View bridge code
Attacker · Round 1

Broadcast Spy — M5

A screen-and-buttons spy. It hears every command in the clear and can replay any of them.

  • Reads the commands and shows them on screen
  • Replay a captured command — the car obeys the impostor
  • Goes blind the moment the radio switches to unicast
Flash & use it View code
Attacker · Rounds 2–3

Monitor Spy — ESP32-C6

A promiscuous sniffer driven from a serial terminal. It catches unicast and even encrypted traffic, and replays packets byte-for-byte.

  • Serial commands to list, pick and replay captured packets
  • Replays verbatim — still works once traffic is encrypted
  • Can't read the command under AES, but can still jam and stall the car

The three rounds

Confidentiality

Round 1 · Broadcast

Everyone hears everything. The broadcast spy reads every command and replays it at will.

Nobody can keep a secret on an open channel.

Integrity & authenticity

Round 2 · Unicast

Commands now go only to the car's address. The broadcast spy goes blind — attackers need the monitor spy — but a replayed packet still hijacks the car.

Addressing a message is not the same as securing it.

Availability

Round 3 · Encrypted

The wand encrypts with the key from its NFC card. The spy can no longer read the command — but the verbatim replay still works, and flooding the stop packet stalls the car.

Encrypting is not authenticating. The fix — HMAC + a sequence number — is the redesign.

Flash the boards

  1. Wands and bridges run MicroPython; copy the file with mpremote: 
    mpremote connect <port> fs cp <file>.py :main.py + reset
  2. The monitor spy is Arduino/C++ on the XIAO ESP32-C6: 
    arduino-cli compile --fqbn esp32:esp32:XIAO_ESP32C6 espiao_monitor_xiao_term
arduino-cli upload -p <port> --fqbn esp32:esp32:XIAO_ESP32C6 espiao_monitor_xiao_term
  3. Watch and drive the monitor spy over serial at 115200 baud, or use the serial console in the browser.

Full, step-by-step install (libraries, VS Code, board firmware) is in INSTALACAO.md, and the complete study guide is in docs/.
